# 🔒 Security

## How the official mod is shipped

- **Only** from this repository's [Releases](../../releases) page.
- A release contains a single `Body_Roadster_SF.upk` file. The installer is the plain-text PowerShell script in `scripts/`, which you can read before running.
- The project **never** distributes `.exe`, `.msi`, `.bat` downloaders, cracked launchers or "skin unlockers".

Fake game-mod downloads are a common way to spread malware. If you find a copy of this mod elsewhere that asks you to run an executable or disable your antivirus, don't run it. Please report it in an issue.

## Reporting a problem

If you find a security issue in the scripts, open an issue with the **security** label, or contact the maintainer privately via the GitHub profile if the details shouldn't be public.
